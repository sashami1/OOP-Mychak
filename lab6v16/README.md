• Лабораторна робота No6

• Тема: Наслідування. Ключові слова base, override, virtual. Приховування членів (new).

• Мета: Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override
для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів
за допомогою new.

• Висновки:

Під час виконання лабораторної роботи було опановано механізми успадкування та поліморфізму в мові C# на прикладі ієрархії класів Document, TextDocument та ImageDocument. На практиці реалізовано виклик конструкторів базового класу за допомогою ключового слова base, а також досліджено фундаментальну різницю між перевизначенням віртуальних методів (virtual / override) та приховуванням членів (new). У результаті було продемонстровано, що метод з модифікатором override забезпечує dynamic (runtime) поліморфізм і викликається залежно від фактичного типу об'єкта в пам'яті, тоді як метод з модифікатором new виконує статичне приховування та викликається відповідно до типу посилання на об'єкт.

• Контрольні запитання:

1. Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.
   Наслідування — це механізм ООП, який дозволяє одному класу успадковувати поля та методи іншого, щоб не дублювати код і розширювати його функціональність. Наприклад, клас "Транспорт" має загальні властивості (швидкість, двигун), а похідний клас "Автомобіль" успадковує їх та додає власні (кількість дверей).

2. Для чого використовується ключове слово base? Наведіть приклади його застосування.
Ключове слово base використовується в похідному класі для доступу до членів базового класу. Воно застосовується для виклику конструктора батьківського класу (base(fileName, fileSize)) або для виклику його методів (base.Open()).

3. У чому полягає різниця між virtual та override? Як вони забезпечують поліморфізм?
Модифікатор virtual у базовому класі дозволяє змінювати реалізацію методу в похідних класах, а override у похідному класі надає цю нову реалізацію. Разом вони забезпечують поліморфізм: при виклику методу через посилання базового типу виконується версія методу того об'єкта, який реально створено в пам'яті.

4. Коли варто використовувати модифікатор new для приховування члена базового класу, і які
наслідки це має?
Модифікатор new використовується для явного приховування члена базового класу, коли в похідному класі потрібно створити метод з таким самим іменем, але без поліморфного зв'язку. Це призводить до того, що викликаний метод залежить від типу змінної (посилання), а не від фактичного об'єкта в пам'яті.
