# Самостійна робота №13 

Тема: Узагальнений кеш Cache<TKey, TValue> із тестами.
Мета: Розробити узагальнений клас кешу з обмеженою ємністю та політикою видалення найстаріших елементів (FIFO), а також покрити його юніт-тестами.

Хід роботи:
1. Створила проєкт IndependentWork_7 та тестовий проєкт IndependentWork_7.Tests (назву папки було змінено на IndependentWork_7, оскільки стандартна назва IndependentWork7 вже була наявна в репозиторії).
2. Реалізувала узагальнений клас Cache<TKey, TValue> на базі Dictionary<TKey, TValue> та Queue<TKey> для забезпечення роботи алгоритму FIFO.
3. Написала 6 xUnit-тестів у проєкті IndependentWork_7.Tests, що покривають додавання, отримання, перевірку наявності, підрахунок елементів та витіснення найстаріших даних при переповненні.
4. Продемонструвала роботу кешу в методі Main.

Контрольні запитання:
1. Переваги Cache<TKey, TValue>: Узагальнення дає типобезпеку під час компіляції та відсутність необхідності приведення типів і boxing/unboxing.
2. Чому Dictionary + Queue зручно для FIFO: Dictionary забезпечує швидкий доступ O(1) за ключем, а Queue зберігає чіткий порядок додавання елементів для їх видалення.
3. Коли викидати KeyNotFoundException: Виняток викидається у строгих методах на кшталт Get, коли відсутність ключа вважається помилкою. Якщо ключ може бути відсутнім у нормальному сценарії — зручніше використовувати TryGetValue.
4. Критичні тести для витіснення: Перевірка перевищення ємності (що видаляється саме найстаріший елемент), перевірка збереження нових елементів та перевірка Count після витіснення.
