# Лабораторна робота №11 

Тема: LINQ: SelectMany, пагінація й custom extensions.
Мета: Навчитися використовувати SelectMany для розгортання вкладених колекцій, реалізовувати пагінацію даних та створювати власні методи розширення.

Хід роботи:
1. Створено консольний проєкт lab17v16.
2. Створено класи University, Student та Course із вкладеними колекціями та заповнила їх тестовими даними.
3. Реалізовано три обов'язкові завдання для варіанту 16:
   - Використано SelectMany для отримання єдиного списку всіх курсів у всіх студентів та університетів.
   - Зроблено посторінкове виведення студентів (пагінація) по 5 осіб на сторінку за допомогою Skip та Take.
   - Створено власний метод розширення IsEnrolledIn для класу Student, який перевіряє, чи вивчає студент заданий курс.
4. Виведено результати роботи в консоль.

Контрольні запитання:
1. Для чого потрібен SelectMany: Вiн розгортає вкладені колекції у один плаский список. Звичайний Select повернув би список списків, а SelectMany одразу об'єднує їх у єдиний потік.
2. Як реалізувати пагінацію: За допомогою Skip(N) (пропустити N елементів) та Take(M) (взяти M елементів). Наприклад, для сторінки P пропускаємо (P-1)*M елементів і беремо M.
3. Що таке методи розширення: Це спеціальні static методи, які додають нові функції до існуючих класів без зміни їх коду, використовуючи ключеве слово this перед першим параметром.
4. Приклад методу розширення для IEnumerable: Наприклад, метод TotalCount(), який приймає this IEnumerable<T> source і повертає кількість елементів у колекції.
