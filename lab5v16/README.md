• Лабораторна робота No5

• Тема: Поліморфізм: динамічне зв’язування та перевизначення методів.

• Мета: Навчитися реалізовувати поліморфну поведінку за допомогою віртуальних методів та їх
перевизначення, а також агрегувати результати поліморфних викликів.

• Висновки:

У цій лабораторній роботі я засвоїла принципи поліморфізму та динамічного зв'язування в мові C#. На практиці створила ієрархію класів із базовим User та похідними Admin, Moderator і Guest, перевизначивши віртуальний метод для демонстрації різної поведінки об'єктів під час виконання програми. Окрім цього, успішно реалізувала збереження об'єктів у спільну поліморфну колекцію та пролистала її для агрегації загальної кількості користувачів у системі.

• Контрольні запитання:

1. Що таке поліморфізм і як він реалізується в C# за допомогою virtual та override?

Поліморфізм — це здатність об'єктів різних класів реагувати на один і той самий виклик методу по-різному, залежно від їхнього фактичного типу. У C# він реалізується через базовий метод із модифікатором virtual, який дозволяє перевизначення, та похідні методи з модифікатором override, які надають власну унікальну реалізацію.

2. Поясніть поняття динамічного зв’язування. Чим воно відрізняється від статичного?

Динамічне (пізнє) зв'язування означає, що конкретна реалізація віртуального методу обирається під час виконання програми (runtime) на основі реального типу об'єкта в пам'яті. На відміну від нього, статичне (раннє) зв'язування відбувається ще під час компіляції (compile time), коли виклик методу чітко прив'язаний до вказаного типу змінної.

3. Наведіть приклад, як поліморфізм дозволяє писати більш гнучкий та розширюваний код.

Поліморфізм дозволяє додавати нові типи об'єктів (наприклад, створити новий клас VIPUser) без зміни існуючої логіки програми. Основний цикл обробки користувачів foreach (User user in users) user.GetPermissions(); буде автоматично працювати з новим класом без редагування його коду.

4. Які переваги дає використання колекцій базових типів для роботи з поліморфними об’єктами?

Використання колекції базового типу (наприклад, List<User>) дозволяє зберігати об'єкти різних похідних класів (Admin, Moderator, Guest) в одному місці та обробляти їх єдиним циклом. Це спрощує структуру коду, усуває дублювання та дозволяє легко проводити загальну агрегацію результатів.
