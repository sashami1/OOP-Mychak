# Звіт з Лабораторної роботи №8 (lab14v16)

**Тема:** Делегати й лямбда-вирази у практиці колекцій: CollectionHelper<T>.

**Мета:** Навчитися передавати поведінку як параметр через делегати Func, Action, Predicate, будувати на цій основі універсальні операції над колекціями та використовувати лямбда-вирази.

## Хід роботи
1. Створила консольний проєкт lab14v16.
2. Реалізувала клас CollectionHelper із власним методом Zip (16 варіант). Метод написаний вручну через цикли та ітератори, без використання готових LINQ-операторів.
3. У методі Main перевірила роботу методу Zip на трьох різних прикладах:
   - Об'єднала список імен (string) та віку (int) у звичайні рядки.
   - Об'єднала ті ж дані, але створила з них об'єкти класу Person.
   - Об'єднала два списки чисел (ціни та знижки) для розрахунку підсумкової вартості.

## Контрольні запитання
1. **Що таке делегат:** Це спеціальний тип даних, який зберігає посилання на метод, щоб його можна було викликати пізніше або передати в інший метод.
2. **Різниця між Func та Action:** Func завжди повертає результат, а Action просто виконує дію і нічого не повертає (void).
3. **Лямбда-вирази та делегати:** Лямбда-вирази дозволяють швидко та коротко записувати анонімні функції прямо в місці передачі делегата.
4. **Переваги узагальнених методів:** Дозволяють написати один універсальний код, який працює з будь-якими типами даних без втрати швидкодії.
