# Звіт з Лабораторної роботи №9 (lab15v16)

Тема: HashSet/Queue/Stack: практичні сценарії.
Мета: Навчитися використовувати колекції HashSet, Queue та Stack для розв'язання практичних задач у C#.

Хід роботи:
1. Створила консольний проєкт lab15v16.
2. Написала систему валідації за варінтом 16, використавши три різні колекції:
   - HashSet — для зберігання унікальних правил валідації (дублікати просто не додаються).
   - Queue — для черги об'єктів, які треба перевірити. Працює за принципом перший прийшов — перший обробився (FIFO).
   - Stack — для зберігання історії помилок. Працює за принципом LIFO, тобто остання помилка буде зверху.
3. У методі Main перевірила роботу всіх цих колекцій та вивела результати в консоль.

Контрольні запитання:
1. Різниця між List та HashSet: List зберігає всі елементи підряд разом з дублікатами і шукає довго, а HashSet зберігає тільки унікальні значення і знаходить їх миттєво.
2. Коли брати Queue: Коли треба обробляти задачі по черзі, у тому порядку, як вони надходили.
3. Приклад для Stack: Кнопка "Назад" у браузері або відміна останньої дії (Undo) у програмах.
4. Складність Contains у HashSet: Працює за O(1), бо елементи шукаються за хеш-кодом, а не повним перебором.
5. Чому FIFO і LIFO: Черга (Queue) працює як реальна черга в магазині (хто перший став, той перший вийшов), а стек (Stack) — як стопка тарілок ( яку поклали останньою, ту першою і заберемо).
